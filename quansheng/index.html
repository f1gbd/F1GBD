Mode d'emploi

    
    
      
  1. La radio doit tourner sous le firmware F4HWN édition Labs (menu Apps). Branchez le câble USB-C (UV-K1 / UV-K5 v3) ou le câble de programmation, radio allumée sur l'écran principal.
    2. 
      
  2. Connecter la radio puis choisissez le port série. La version du firmware et les 16 emplacements s'affichent.
    3. 
      
  3. Choisissez l'application (catalogue ou fichier .app), puis l'emplacement : celui d'une version précédente de la même application est proposé d'office, ses réglages (code d'activation, sirène…) sont conservés.
    4. 
      
  4. Installer : effacement, écriture des ressources, du code puis de l'en-tête, et vérification. L'application apparaît ensuite dans le menu Apps de la radio.
    5. 
    

    
Une application overlay est du code natif : n'installez que des fichiers de confiance. Le chargeur de la radio refuse toute image dont le CRC, l'ABI ou l'adresse d'overlay ne correspondent pas au firmware.
