Montre TML v1.1

La messagerie LXMF d'urgence au poignet, reliée en ESP-NOW au TransMiniLora.

Ce navigateur ne gère pas le Web Serial. Utilisez Chrome ou Edge sur ordinateur. Le flashage web exige une page en HTTPS.

Chrome ou Edge, sur ordinateur. Environ 1,2 Mo, une minute.

Une seule carte est compatible : la Waveshare ESP32-S3-Touch-AMOLED-2.06. Ce binaire ne convient ni à la variante ESP32-C6, dont le brochage diffère, ni à aucune autre carte — l'écran resterait noir.

Avant de flasher

  1. Brancher la montre sur un port USB-C avec un câble de données : beaucoup de câbles ne portent que l'alimentation.
  2. Fermer tout ce qui pourrait tenir le port série : moniteur, IDE, autre onglet de flashage.
  3. Cliquer sur le bouton, puis choisir le port dans la fenêtre du navigateur.
  4. Si aucun port n'apparaît, maintenir BOOT enfoncé, brancher le câble, relâcher.

Il faut aussi un TransMiniLora

La montre ne transmet rien elle-même. Le TransMiniLora reste le modem LoRa et la pile Reticulum / LXMF, et doit tourner avec un firmware intégrant le pont ESP-NOW.
